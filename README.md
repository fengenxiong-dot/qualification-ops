# 任职资格认证运营台

把资格标准、员工举证、评审记录和认证结果，串成可追溯的管理流程。

[项目主页](https://github.com/fengenxiong-dot/qualification-ops) · [作者与项目合集](https://github.com/fengenxiong-dot) · [许可证](LICENSE)

## 为什么做这个工具

任职资格管理涉及标准开发、员工申报、材料回收、评委评分和结果确认。分散在表格和文件夹里时，版本容易混淆，历史记录也难以追溯。这个项目来自 HR 资格认证工作的流程整理需求，尝试用一个本地工作台管理从标准到结果的全过程。

## 核心功能

- 按职族、职类和子类维护资格标准，支持分级矩阵。
- 标准开发、定稿存档、历史快照和版本迭代。
- 被评价人逐项填写工作成果、行为举证与自评，保存草稿并提交。
- 导入 Excel 申请与相关材料，保留原文件及待确认批次。
- 配置评委和评价关系，录入分项评分与反馈。
- 管理人员档案、认证结论、职级变化及历史补录。
- 导出人员档案、评审明细与认证记录，并保留关键操作痕迹。

## 适合哪些场景

- 企业专业序列或管理序列的任职资格认证。
- 岗位能力标准开发和周期性认证组织。
- 需要关联材料、分数与历史结论的内部评审。

## 第一次使用

### 准备环境

Python 3 与 `requirements.txt` 中的依赖。服务使用 SQLite 保存数据，可先在本机浏览器体验。

下载方式：会使用 Git 可按下面的命令克隆；也可在本页点击 **Code → Download ZIP**，解压后在项目目录打开终端，跳过 `git clone` 和 `cd` 两步。

### 安装与启动

```sh
git clone https://github.com/fengenxiong-dot/qualification-ops.git
cd qualification-ops
python -m pip install -r requirements.txt
python server.py
```

打开 `http://127.0.0.1:8787`。

### 操作流程

1. 先建立测试职族、职类与子类，再创建资格标准。
2. 补齐各等级要求，核对内容后定稿存档。
3. 使用虚构人员创建申请，逐项提交举证或导入测试 Excel。
4. 配置评委及权重，录入评分并检查汇总。
5. 由管理员人工确认认证结果和生效信息。
6. 导出个人档案，核对历史与材料关联，并备份数据目录。

## 当前状态与限制

导入规则包含特定申请表结构，自己的 Excel 模板可能需要适配。系统用于流程管理，认证、晋级等结论仍由有权人员确认。上线前需检查身份验证、访问权限和备份；本次未重新验收所有浏览器交互及 Linux/Windows 部署方式。

**验证情况：** 本次开源检查通过 55 项 Python 测试，仍存在数据库连接关闭相关 ResourceWarning。

## 数据保存与配置

`data/certification.db` 保存业务记录；`data/submissions/` 保存附件，`data/staging/` 保存待确认批次。停止服务后备份整个 `data/`。

公开仓库只提供源码与示例配置。真实人员资料、业务文件、数据库和 API Key 需要由使用者自行管理。先用虚构数据走通流程，确认符合自己的需求后再投入实际工作。
